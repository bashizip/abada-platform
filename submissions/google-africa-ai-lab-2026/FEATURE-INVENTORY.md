# Sellable Feature Inventory

This inventory separates current product evidence from bounded compatibility
and program roadmap claims.

| Priority | Capability | Customer value | Status |
|---:|---|---|---|
| 1 | Full process lifecycle | Design or import, test, deploy, operate and improve in one platform | Implemented |
| 2 | Governed Insight Engine | Runtime facts become validated proposals with human review | Implemented; disabled by default |
| 3 | Hybrid AI orchestration | Agents, humans, decisions and systems share durable state | Implemented |
| 4 | PostgreSQL runtime | Restart recovery, leases, immutable versions, idempotency and outbox | Implemented |
| 5 | Operational Studio | Visual authoring, Dry Run, live inspection, tasks and Insight review | Implemented |
| 6 | Governance | Backend RBAC, audit, reviewer policies and model allow-lists | Implemented |
| 7 | BPMN interoperability | Direct execution, Studio import and supported round-trip | Limited to documented subset |
| 8 | Self-hosting | Operator controls infrastructure, models and data location | Implemented; cloud certification pending |
| 9 | APL and AI authoring | Native, diffable representation validated before deployment | Implemented |
| 10 | Gemini function calling, multimodal and African languages | Lab acceleration roadmap | Roadmap |

## Claim controls

- Say **governed improvement**, never silent or autonomous self-modification.
- Insight currently detects failure rate, p95 latency regression and decision fallback thrash.
- Insight proposals currently adopt new native APL versions and never rewrite running instances.
- Say **supported BPMN subset**, never full BPMN compatibility.
- Treat APL and BPMN import as entry mechanisms, not Abada's complete value proposition.
