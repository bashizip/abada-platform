# Abada 1.1.2 release notes

Released 2026-10-17 on top of [1.1.1](1.1.1-release-notes.md). It changes
only the one-line installer; the engine, Studio, the agent worker, the API,
the worker protocol and the schema (`V39`) are the same as in 1.1.1.

## Fix

- **Re-running the installer updates an existing installation.** When the
  install directory already held a `.env.dev`, the installer kept it untouched:
  it downloaded the new release but started the image tags the earlier release
  had pinned (found when a 1.1.1 install pulled `1.0.0-rc.3` images). It now
  saves the file as `.env.dev.backup-<date>`, sets the image tags of the
  release it installs, appends settings the release introduced, keeps every
  other setting, and prints `Updating the existing installation in … from
  <old> to <new>`. The installer distribution test covers the update; it fails
  on the 1.1.1 script.

## Upgrade

Run the installer again:

```bash
curl -fsSL https://install.abadaplatform.com/install.sh | bash
```

If you updated with the 1.1.1 installer over an earlier installation, check
the four `ABADA_*_IMAGE` lines in `.env.dev` (see
[Upgrading](../operations/upgrading.md#updating-with-the-one-line-installer-112-and-later)).
No migration; rolling back to 1.1.1 is an image change only.

## Known limitations

Unchanged from [1.1.1](1.1.1-release-notes.md#known-limitations).
