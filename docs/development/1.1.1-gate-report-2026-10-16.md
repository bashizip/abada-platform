# Abada 1.1.1 publication gate report — 2026-10-16

Patch release of `1.1.0`. Scope: two defects found by a clean-machine install of
the published `1.1.0` (all Abada containers, volumes and images removed, then the
public `curl -fsSL https://install.abadaplatform.com/install.sh | bash` with no
model key). No feature, migration, API or worker-protocol change. Release notes:
[`1.1.1-release-notes.md`](../release-notes/1.1.1-release-notes.md).

## Findings that triggered the patch

| Finding on 1.1.0 | Fix | Evidence |
| --- | --- | --- |
| First sign-in: concurrent requests each created the principal; all but one failed on `uq_principal_issuer_subject` with 500 (`/apl/schema`, `/ai-providers/status`) | `PrincipalService.observe` retries once in a new transaction | `PostgresPrincipalFirstSightTest`: fails on 1.1.0 (7 of 8 concurrent requests), passes on 1.1.1 |
| `curl \| bash`: `docker compose exec` in `up dev` consumed the rest of the piped script; exit 0 without bob's account, the missing-key hint or the manage commands | Script body parsed as one block; `up dev </dev/null` | `verify-install-distribution.sh` piped case: fails on 1.1.0, passes on 1.1.1 |

The clean install itself succeeded on 1.1.0 (5 min 02 s to all eight containers
healthy on Apple silicon, published GHCR images, checksum verified), and Studio's
refusal to start an agent process without a configured provider shows its message.
