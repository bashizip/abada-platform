# Abada 1.0.0-rc.6 publication gate report — 2026-09-23

## Decision

**NO-GO (pending) — `1.0.0-rc.6` evaluation release candidate.**

Local verification of the M1 "truth and safety" candidate is complete and
green, but four release-blocking items are open (see
[Open items](#open-items)): the M1 exit demo, Alloy validation through the
unmodified contract script, the merge of the candidate into `dev`, and release
owner sign-off. The decision changes to **GO conditional on the exact tag
workflow** only when all four are closed and recorded here.

This candidate keeps the evaluation scope of the 1.0 RC line (see
`1.0-rc-publication-gates.md`, rc.1 and rc.5 scope sections): public-cloud
TLS/external-OIDC certification, multi-host failover, rolling upgrades,
production backup/restore, live telemetry certification, Windows quickstart
CI, image attestations and independent security review remain deferred and
are not claimed here.

## Open items

1. **Alloy validation through the unmodified script.** A Docker Desktop crash
   during the pull left the local arm64 `grafana/alloy:v1.18.0` layer with
   zero-byte system files (`exec /bin/alloy: input/output error`); deleting
   and re-pulling reuses the corrupted snapshot. The pinned v1.18.0 binary,
   extracted intact from the image and run on `ubuntu:24.04`, validates
   `deployment/telemetry/config.alloy` (exit 0). That is supporting evidence
   only. Close by running `./scripts/test/validate-platform-deployment.sh`
   without `ABADA_CONTRACT_SKIP_LIVE_PREFLIGHT` after the local image store is
   repaired, or in CI.
2. **M1 exit demo** (roadmap): a malicious expression is rejected at deploy;
   invalid or low-confidence agent output routes to a human; four slow agent
   tasks produce no duplicate model call; site and brief claims match the code.
   Record workflow IDs and logs here. The PDF brief has no source in the
   repository and must be corrected by hand.
3. **Merge into `dev`** through a reviewed PR; record the merge commit.
4. **Release owner sign-off** on this report.

Create and push `v1.0.0-rc.6` only from the reviewed merge commit in `dev`,
