# Abada 1.1.2 publication gate report — 2026-10-17

Release of 2026-10-17 on top of `1.1.1`. Scope: the one-line installer only
([release notes](../release-notes/1.1.2-release-notes.md)). The engine,
Studio, agent worker, API, worker protocol and schema (`V39`) are the code of
`1.1.1`; only their version number changes.

## Finding

Running the public installer (`curl -fsSL https://install.abadaplatform.com/install.sh | bash`)
from a directory that held an earlier installation downloaded and verified
the `1.1.1` archive, then started the `1.0.0-rc.3` images pinned by the
existing `.env.dev`, which the installer kept untouched. On a database already
at `V39` that engine would not start. The run was stopped before the rc.3
engine and Studio containers started; the schema was checked at `V39`.

| Fix | Evidence |
| --- | --- |
| On an existing `.env.dev` the installer backs it up, sets the release's image tags, appends new settings, keeps the rest and says it is updating | `verify-install-distribution.sh` update case (old rc.3 tags, an operator password, an unknown operator setting): fails on the 1.1.1 script, passes |
