`1.2.0` closes milestone M5 *Studio experience* (S1–S15, scope frozen on
2026-11-12). It adds Flyway `V40` to `V44` (all additive) and additive
endpoints and fields; REST API v1 and worker protocol v1 stay backward
compatible. RustFS becomes a required service of self-hosted installations.
See [`1.2.0-release-notes.md`](../release-notes/1.2.0-release-notes.md) and
the [upgrade section](../operations/upgrading.md).

The evidence comes from a local Linux host (Java 21, Docker 29.9, Node
22.23 instead of the 24.18 pinned in `.nvmrc`). A publication needs the CI run
on the release commit and the tag workflow on the exact tagged commit.

## Not done / to do before GO

- **Production images.** A local `docker build` of the four images could not
  run on this host: Docker Hub answered `429 Too Many Requests` and the build
  containers could not reach the Alpine and Maven repositories. The image
  evidence must come from the `docker-publish-ghcr` run on `dev` after this
  branch merges (all four images), then from the tag workflow.
- **Real-provider file check.** S15 provider wire formats (Gemini, OpenAI,
  OpenRouter, Anthropic) are tested against stub servers only. Run one
  `scanned-invoice` instance against a real Gemini key on the GCP demo VM.
- **Exit demo:** record the retry playing out and the NL workspace apply.
- **Node version:** re-run the Studio and documentation checks on Node 24.18
  (CI does).
- **Flaky e2e.** The Studio Playwright test "a failed refinement leaves the
  canvas untouched" can fail because drafts land in a project the test does
  not own (a race in the test's project switch). Test-harness issue, not a
  product defect; to be fixed in 1.2.x.
