# Abada 1.0.0-rc.4 publication gate report — 2026-08-30

## Decision

**GO — `1.0.0-rc.4` evaluation release candidate, conditional on the exact
tag workflow succeeding.**

The release owner explicitly authorized Codex to prepare, tag and publish
RC.4 in the current release thread on 2026-08-30. This decision retains the
evaluation scope already documented for the 1.0 RC line: public-cloud
TLS/external-OIDC certification, multi-host failover, rolling upgrades,
production backup/restore, image attestations and independent security review
remain deferred to the 1.1 infrastructure roadmap and are not claimed here.

The tag workflow is part of the gate. A failure in image publication, public
artifact verification, anonymous image access, clean-runner installation,
stack startup or `/latest` promotion returns this decision to **NO-GO**.

## Publication condition

Create and push `v1.0.0-rc.4` only from the reviewed release-preparation commit.
The reusable release workflow must finish successfully before RC.4 is treated
as published. It promotes `/latest` last, so an incomplete release cannot
become the installer default.
