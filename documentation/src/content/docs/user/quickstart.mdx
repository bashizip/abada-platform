One command installs a complete local platform: **PostgreSQL**, the
**Engine**, **Studio**, the **Agent Worker** and a development **Keycloak**,
behind a local HTTP edge. You need Docker with Compose v2.

## Install

```bash
mkdir abada-quickstart && cd abada-quickstart
curl -fsSL https://install.abadaplatform.com/install.sh | bash
```

The installer asks for a Gemini API key (hidden input) and checks that it can
call `gemini-3.6-flash`. You can skip it and add any provider later in
**Studio → Settings → AI Providers**. The key is written only to the local,
untracked `.env.dev` (mode `0600`). Automation can pass it as
`ABADA_LLM_GEMINI_API_KEY`.

On Windows (PowerShell):

```powershell
New-Item -ItemType Directory abada-quickstart
Set-Location abada-quickstart
Invoke-WebRequest https://raw.githubusercontent.com/bashizip/abada-platform/main/release/quickstart.ps1 -OutFile quickstart.ps1
.\quickstart.ps1
```

Images are published for `linux/amd64` and `linux/arm64`.

## Sign in

When the installer finishes it prints the URLs and accounts:

| What | Where |
| --- | --- |
| Studio | `http://studio.localhost` (or `http://localhost:5605`) |
| Engine information | `http://api.localhost/api/v1/info` |
| Keycloak (development only) | `http://keycloak.localhost` |

Sign in to Studio as **alice** / `alice`. A second account, **bob** / `bob`,
is useful to play the reviewer. These are local development credentials;
never reuse them elsewhere.

Studio's header has four views — **Canvas**, **Task Inbox**, **Operations**
and **Insight** — plus **Admin** for members of `abada-admin`.

## Run the starter

On first sign-in, Studio creates the **Abada Starter** project and deploys the
**AI Lead Triage** process. Open **Deploy & Start**: it offers HIGH, MEDIUM and
LOW sample inputs.

- A HIGH lead creates a review task for **bob**: sign in as bob, open **Task
  Inbox**, claim the task and complete its form.
- The **four LOW samples** action feeds the [Insight
  Engine](/user/studio-insight/), which then proposes an improvement for a
  human to review. The model calls run one after another with a quota-safe
  delay; allow about five minutes.

## Check and stop

```bash
curl -fsS http://api.localhost/api/actuator/health/readiness
cd abada-platform
./release/abada-platform status dev
./release/abada-platform down dev
```
