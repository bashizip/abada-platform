---
title: Development deployment
description: Run the complete local HTTP platform with PostgreSQL and Keycloak.
---

From a repository clone or extracted release archive:

```bash
./release/abada-platform doctor dev
./release/abada-platform up dev
```

The first command creates `.env.dev` from `release/.env.dev.example`, validates
Docker and Compose, checks ports and image availability, and renders the final
configuration. The stack exposes only Traefik on port 80 and its loopback-only
dashboard on 8080. PostgreSQL is not published to the host.

## Development identities

The bundled realm separates task work from operational access:

| Application | Username | Password | Access |
| --- | --- | --- | --- |
| Tenda | `alice` | `alice` | Task user, process control and deployment |
| Orun | `orun-admin` | `orun-admin` | Operations access |
| Keycloak administration | `admin` | `admin` | Development realm administration |

Keycloak single sign-on can reuse Alice's session when Orun is opened after
Tenda. Select **Sign out and switch account** on the Orun access screen, then
authenticate as `orun-admin`. All three accounts are development-only.

Core Compose equivalent:

```bash
docker compose -f compose.yaml -f compose.dev.yaml up -d
```

Bundled telemetry:

```bash
./release/abada-platform up dev --telemetry
# equivalent overlay:
docker compose -f compose.yaml -f compose.dev.yaml \
  -f compose.telemetry.yaml up -d
```

Operations:

```bash
./release/abada-platform status dev
./release/abada-platform logs dev
./release/abada-platform down dev
```

To delete local databases as well, use `docker compose` with the same files and
run `down -v`. This permanently removes workflow and Keycloak data.
